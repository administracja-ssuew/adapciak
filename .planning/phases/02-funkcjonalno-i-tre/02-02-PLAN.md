```javascript
/* ─── UX-01: Navbar hide on scroll (mobile only) ─── */
(function initNavbarScroll() {
  var navbar  = document.getElementById('navbar');
  var lastY   = 0;
  var ticking = false;

  window.addEventListener('scroll', function() {
    if (!ticking) {
      requestAnimationFrame(function() {
        var currentY = window.scrollY;
        if (window.innerWidth < 768) {
          if (currentY > lastY && currentY > navbar.offsetHeight) {
            navbar.classList.add('nav-hidden');
          } else {
            navbar.classList.remove('nav-hidden');
          }
        } else {
          navbar.classList.remove('nav-hidden');
        }
        lastY = currentY;
        ticking = false;
      });
      ticking = true;
    }
  }, { passive: true });
})();
```

Important constraints:
- Do NOT modify the existing `#navbar` element's class attribute in HTML
- Do NOT touch `initGallerySlider` or any other existing IIFE
- The CSS transition rule targets `#navbar` by ID — it will not conflict with any existing `.reveal` transitions which target `.reveal` class
- The scroll handler checks `window.innerWidth < 768` on every scroll event, so resizing the window from mobile to desktop automatically removes the `nav-hidden` class — no separate resize listener needed

```javascript
/* ─── UX-02: Back-to-top button ─── */
(function initBackToTop() {
  var btn = document.getElementById('back-to-top');
  if (!btn) return;

  window.addEventListener('scroll', function() {
    if (window.scrollY > 400) {
      btn.classList.add('visible');
    } else {
      btn.classList.remove('visible');
    }
  }, { passive: true });

  btn.addEventListener('click', function() {
    window.scrollTo({ top: 0, behavior: 'smooth' });
  });
})();
```

Important constraints:
- The button starts with `opacity-0 pointer-events-none` (Tailwind classes) — the `visible` class (defined in CSS) overrides both to `opacity: 1; pointer-events: auto`. Do NOT use `hidden` class — that uses `display:none` which prevents CSS transition.
- Do NOT use `display: none / block` toggling — the opacity + pointer-events approach enables a CSS fade transition if desired later.
- `window.scrollTo({ behavior: 'smooth' })` works cleanly alongside `html { scroll-behavior: smooth }` already on the page.
